# 技艺实体表现 v3：动漫风

替代 v2 的贴图球体 / 贴图平面。五个弹体技艺（灵斩、风斩、波动拳、八阵图、豪火球）的特效全部改为程序生成的动态几何：
纯色三角面拼出赛璐璐式色阶（外深内浅 + 白芯），叠加加法混合的光晕、流光与闪光，每帧变形。不再使用任何贴图
（`textures/entity/art/*.png` 与生成脚本已删除）。

## 渲染

- `client/fx/ZsRenderTypes`：`TOON`（普通透明混合）与 `GLOW`（加法混合），位置 + 颜色顶点，双面，深度测试但不写深度。
  每个实体先画完 TOON 再画 GLOW，两种缓冲不交错。
- `client/fx/AnimeFx`：图元——噪声火焰 / 能量团（带沿屏幕运动方向反向拉长的尾焰）、圆环 / 弧、冲击放射、菱形针、
  四芒闪光、新月刀光（可只画一段以做“划出”动画）、沿飞行轴的流光。
- `client/ArtProjectileRenderer`：按种类绘制。
- `client/ClientArtScreenFx`：蓄力时（第一人称）屏幕集中线；波动拳命中 / 豪火球爆炸时一帧白闪 + 黑色冲击集中线，
  并按距离触发震屏（每个特效实体只触发一次）。

## 动作与出手同步

动作由 `tools/gen_art_anims.py` 重新生成，五个技艺动作各不相同，节奏为“预备 → 极快出招 → 定格 → 缓收”，并使用肘弯：

- 灵斩：手按刀柄拧腰 → 一闪横斩至右上方 → 残心。
- 风斩：双手举过右肩（回弹）→ 斜劈至左下，深弓步。
- 波动拳：蓄力时沉腰、双掌合于右腰后侧并逐渐加剧颤抖；释放时双掌前推并略回弹。
- 八阵图：蓄力时右手剑指立于面前、左手掐诀，缓慢吐纳；释放时剑指前点、左掌外展。
- 豪火球：0.6 秒内连续结印，随后寅印置于口前后仰吸气；释放时再吸一口、猛然前倾喷吐。

服务端在施法时扣费并播放动作，弹体在动作的出招帧才发出（灵斩 4 tick、风斩 5 tick、波动拳 2 tick、豪火球 3 tick；
八阵图即时），瞄准取发出那一刻的视线。出招前死亡、下线或换维度则这一招作废。

## 兼容

`ArtProjectile` 同步数据由布尔“跟随”改为整数跟随方式（视线前 / 右腰 / 口前），网络协议升至 18，客户端与服务端需同时升级。

## v3.1：弹幕血量、灵斩竖劈、能量池徽记

### 弹幕血量

灵斩、风斩、波动拳、豪火球与八阵图激光都是有血量的实体弹幕：

- 血量 = 施放威力（检定 × 蓄力倍率 × 留手比例）；八阵图三道激光各取一半。
- 可被攻击：近战（力量 + 对应专业 + 武器伤害，目标防御视为 0）、箭矢 / 三叉戟（敏捷 + 运动 + 弹体伤害），均走 20%~100% 浮动；
  其他来源（枪械等）按原伤害。施法者本人及其盟友的攻击无效；本地玩家自己的弹幕不挡准星。
- 敌对弹幕相撞：双方各扣去较小一方的剩余血量，弱者碎裂、强者带着剩余血量继续飞；同归于尽时都碎裂。
  同一施法者或盟友的弹幕互相穿过。
- 命中伤害按剩余血量比例降低（满血 = 原伤害）；豪火球爆炸同样按爆炸时的剩余血量比例。
- 受击 / 对撞后弹幕上方出现细血条（绿 → 黄 → 红，带白色延迟扣血段），2 秒后淡出。
- 碰撞箱改为以弹幕为中心、按碰撞半径缩放，便于近战与箭矢命中。

### 灵斩竖劈

灵斩刀光改为竖立（略带倾斜），出手残光自上而下划出；动作改为单手举刀过顶 → 一刀竖劈，左手剑指护胸后甩向身后，
与风斩的双手过肩斜劈区分开。

### 能量池 HUD

左侧一排细竖条，每条顶部一枚圆形单字徽记（灵 / 精 / 妖 / 佛 / 魔 / 道 / 能 / 内 / 查 / 仙 / 意；自定义池取名称首字），
徽记外圈弧长也表示剩余量。池满且静置时收窄变暗；未满时中等宽度；数值变化后 3 秒内加宽高亮并竖排显示具体数值。
扣减时徽记轻弹并红闪、回复时白闪，低于两成时外圈红色呼吸；内力吐息时金色描边。打开聊天栏时鼠标悬停显示全名与数值。

弹幕新增血量同步数据，网络协议升至 19，客户端与服务端需同时升级。

## v3.2：其余 14 个技艺、技艺伤害类型、按预设显示能量池

### 非弹体技艺的特效与动作

新增纯视觉实体 `ArtVfx`（`art_vfx`），渲染器 `ArtVfxRenderer`。画风与弹体技艺一致：程序生成的纯色几何、赛璐璐色阶 + 白芯 + 加法光晕，
每帧动态变形，不用贴图球 / 贴图平面。每个技艺都有独立的动作（`tools/gen_art_anims.py` → `art.json`）和独立的造型：

| 技艺 | 动作 | 特效 |
| --- | --- | --- |
| 灵力治疗 | 双掌收于胸前后柔和送出 | 螺旋上升的光带、十字光点、地面光环；治疗他人时有一道光流从手中流向目标 |
| 精神冲击 | 剑指抵太阳穴，头部前送 | 额前浮现第三只眼，射出带双螺旋的精神涟漪光束，命中处同心震环 |
| 精神震荡 | 双手抱头蓄念，双臂猛然张开 | 目标头部炸开三轴陀螺震环、中空冲击圆盘、青 / 品红色差的故障条纹；被击中的玩家屏幕震颤 |
| 息法 | 双掌合十，深吸、长呼 | 脑后法轮、由外向内收拢的吐纳光环；外息金色护体光流、中息足下白色莲纹、内息胸前紫色心灯（按已习得的息叠加） |
| 夜叉空行 | 屈膝蓄势，腾身而起、双臂后展 | 背后羽翼由收拢到展开并缓慢扇动，足下上升气流，飘落光羽 |
| 魔能爆 | 右掌后引，单掌推出，左手扣腕 | 掌前六芒魔法阵（内外环反向旋转、刻度符文），射出奥术光枪，沿途留下旋转符文，命中处小法阵碎裂；研发力场后多一圈力场冲击环 |

结算节奏：动作出手帧生成特效，特效到达目标时才结算伤害 / 治疗（约 0.15~0.65 秒）。出手前施法者死亡、下线或换维度则这一招作废，
费用照付（与弹体技艺一致）。无视我在碎散完成时才进入隐身。

`ZsRenderTypes.TOON / GLOW` 注册为独立渲染缓冲（`RegisterRenderBuffersEvent`），同一帧内交替取用两种缓冲不会互相提前提交。

### 技艺伤害类型

技艺伤害不再一律记为原版“间接魔法”。15 种伤害类型各注册一个伤害类型 `zhushenspace:art_<类型>`（带死亡信息），
技艺按原本的伤害类型使用对应的伤害来源（灵斩纯能量、风斩挥砍、波动拳钝击、豪火球 / 凤仙火火焰、八阵图按元素、精神冲击纯能量或心灵、
精神震荡纯能量、魔能爆钝击或力场、五行纯能量、生物闪电闪电）。远程技艺的直接来源为空（不是亲手近战），
不再误触发内力吐息、太极徒手加成、近战伤害上限等只针对近战的效果；技艺命中前计算的目标防御也不再把玩家护甲当作被魔法无视。

伤害数字颜色（DuMmmMmmy 等按伤害类型标签着色的模组）：火焰橙、寒冷冰蓝、闪电黄、强酸 / 毒素绿、邪恶灰，其余（物理、纯能量、心灵、力场……）为白色，
不再显示为魔法紫。只加入了显示用标签和原版 `is_lightning`，不影响伤害结算。

### 能量池 HUD 按预设显示

只显示当前使用中的战斗预设栏（A / B）里有技能会消耗的能量池：技艺 → 所属能量池（查克拉忍术另含仙术查克拉）；
内力系与太极流派技能 → 内力；内力吐息开启中 → 内力。意志力不由技能消耗，始终显示。界面设置预览仍显示全部能量池。

新增实体与同步数据，网络协议升至 20，客户端与服务端需同时升级。游戏内视觉效果未实机验收。
