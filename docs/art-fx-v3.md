# 技艺实体表现 v3：动漫风

替代 v2 的贴图球体 / 贴图平面。五个弹体技艺（灵斩、风斩、波动拳、八阵图、豪火球）的特效全部改为程序生成的动态几何：
纯色三角面拼出赛璐璐式色阶（外深内浅 + 白芯），叠加加法混合的光晕、流光与闪光，每帧变形。不再使用任何贴图
（`textures/entity/art/*.png` 与生成脚本已删除）。

## 渲染

- `client/fx/ZsRenderTypes`：`TOON`（普通透明混合）与 `GLOW`（加法混合），位置 + 颜色顶点，双面，深度测试但不写深度。
  每个实体先画完 TOON 再画 GLOW，两种缓冲不交错。
- `client/fx/AnimeFx`：图元——噪声火焰 / 能量团（带沿屏幕运动方向反向拉长的尾焰）、圆环 / 弧、冲击放射、菱形针、
  四芒闪光、新月刀光（可只画一段以做“划出”动画）、沿飞行轴的流光。
- `client/ArtProjectileRenderer`：按种类绘制。
- `client/ClientArtScreenFx`：蓄力时（第一人称）屏幕集中线；波动拳命中 / 豪火球爆炸时一帧白闪 + 黑色冲击集中线，
  并按距离触发震屏（每个特效实体只触发一次）。

## 动作与出手同步

动作由 `tools/gen_art_anims.py` 重新生成，五个技艺动作各不相同，节奏为“预备 → 极快出招 → 定格 → 缓收”，并使用肘弯：

- 灵斩：手按刀柄拧腰 → 一闪横斩至右上方 → 残心。
- 风斩：双手举过右肩（回弹）→ 斜劈至左下，深弓步。
- 波动拳：蓄力时沉腰、双掌合于右腰后侧并逐渐加剧颤抖；释放时双掌前推并略回弹。
- 八阵图：蓄力时右手剑指立于面前、左手掐诀，缓慢吐纳；释放时剑指前点、左掌外展。
- 豪火球：0.6 秒内连续结印，随后寅印置于口前后仰吸气；释放时再吸一口、猛然前倾喷吐。

服务端在施法时扣费并播放动作，弹体在动作的出招帧才发出（灵斩 4 tick、风斩 5 tick、波动拳 2 tick、豪火球 3 tick；
八阵图即时），瞄准取发出那一刻的视线。出招前死亡、下线或换维度则这一招作废。

## v3.1：弹幕血量、灵斩竖劈、能量池徽记

### 弹幕血量

灵斩、风斩、波动拳、豪火球与八阵图激光都是有血量的实体弹幕：

- 血量 = 施放威力（检定 × 蓄力倍率 × 留手比例）；八阵图三道激光各取一半。
- 可被攻击：近战（力量 + 对应专业 + 武器伤害，目标防御视为 0）、箭矢 / 三叉戟（敏捷 + 运动 + 弹体伤害），均走 20%~100% 浮动；
  其他来源（枪械等）按原伤害。施法者本人及其盟友的攻击无效；本地玩家自己的弹幕不挡准星。
- 敌对弹幕相撞：双方各扣去较小一方的剩余血量，弱者碎裂、强者带着剩余血量继续飞；同归于尽时都碎裂。
  同一施法者或盟友的弹幕互相穿过。
- 命中伤害按剩余血量比例降低（满血 = 原伤害）；豪火球爆炸同样按爆炸时的剩余血量比例。
- 受击 / 对撞后弹幕上方出现细血条（绿 → 黄 → 红，带白色延迟扣血段），2 秒后淡出。
- 碰撞箱改为以弹幕为中心、按碰撞半径缩放，便于近战与箭矢命中。

### 灵斩竖劈

灵斩刀光改为竖立（略带倾斜），出手残光自上而下划出；动作改为单手举刀过顶 → 一刀竖劈，左手剑指护胸后甩向身后，
与风斩的双手过肩斜劈区分开。

### 能量池 HUD

左侧一排细竖条，每条顶部一枚圆形单字徽记（灵 / 精 / 妖 / 佛 / 魔 / 道 / 能 / 内 / 查 / 仙 / 意；自定义池取名称首字），
徽记外圈弧长也表示剩余量。池满且静置时收窄变暗；未满时中等宽度；数值变化后 3 秒内加宽高亮并竖排显示具体数值。
扣减时徽记轻弹并红闪、回复时白闪，低于两成时外圈红色呼吸；内力吐息时金色描边。打开聊天栏时鼠标悬停显示全名与数值。

弹幕新增血量同步数据，网络协议升至 19，客户端与服务端需同时升级。
