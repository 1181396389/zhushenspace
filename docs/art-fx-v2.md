# 技艺实体表现 1.0.1

替代 v1 通用几何特效总线；移除 ClientArtFx/FxEventPayload 与延时视觉命中。

## 表现与规则

- 风斩：挥斩动作 + 淡青绿笔触斩击实体，16格射程；碰撞结算并击飞。
- 灵斩：同一实体系统的青白灵刃，保留决心射程。
- 波动拳：按住腰侧蓄气，松开双掌前推，发射带流动材质的立体长条波动弹；50格射程。
- 八阵图：按住举掌，前方竖立八卦阵（八个不同卦象+阴阳中心），随轮盘元素着色；释放后发出三道同色激光弹。同次施放对同一目标最多结算一次，避免弹幕凭空三倍伤害；20格射程。
- 豪火球：按住结印至少0.6秒、松开从口前吐出大型火球（起飞时长大）；40格射程。碰撞后爆炸，伤害直径20格/半径10格，蓄力不扩大范围。球形距离检查、效果线遮挡、反射豁免、3秒点燃；不破坏地形，不伤施法者/盟友，尊重玩家PVP开关。

波动拳、八阵图、豪火球：服务端40 tick达到满蓄，伤害倍率1至2倍，原基础能耗不变。按下不扣能量、不进入冷却；有效释放时重新验证条件后扣能量并进入冷却。豪火球过早松开则取消。持续按住超过10秒自动取消，不会自动发射。

死亡、退出、换维度、技能槽变化、失能或封印取消蓄力；打开界面、切换战斗模式/技能栏、窗口失焦客户端发送取消。每次蓄力有序列号，重复释放不会重复出招。伤害参数在释放时快照，防御在真实碰撞时计算，不再先掉血后播放视觉命中。

只有上述三个技能接入按住蓄力；其他未明确要求的技能与波动拳研发分支不做虚构实现。其余原有技能表现未统一迁移。

## 刷屏修复

旧逻辑把所有内力池误当作太极饰品的池：移除专长池后容量同步又立即重建，每10 tick循环删除并提示。新逻辑持久化池来源，只撤销饰品自己创建的池，保留专长/指令池。提示仅在真实装备状态切换时发送；不再反复清空技能栏。旧档无来源标记时保守保留池，避免误删独立来源。

## 资源与构建

实体贴图由 `tools/gen_art_entity_textures.py` 原创生成；动作由 `tools/gen_art_anims.py` 生成，包含蓄力/结印与释放两个阶段。客户端需要 Player Animator；Curios 为项目已有必需依赖。所有新实体短时存在，不存档、不强加载区块。

构建任务改为 `assemble`，不运行测试。需要客户端与服务端同时升级至1.0.1。游戏内视觉效果未实机验收。
