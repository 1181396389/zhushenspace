## 专业

- 新增武器分类：拳套、短棍、长棍、战锤、巨锤、匕首、短剑、弯刀、刀、长刀、斧、短矛、长矛、鞭子、镰刀、弩（共 30 个分类，追加在 `WeaponCategory` 末尾，按 key 存档；专业位掩码要求分类序号 < 32）。长剑 / 重剑沿用已有分类。
- 原版斧头经 `weapons/axe` 标签归入「斧」（与原版剑归入长剑一致）。
- 白刃组专业选项超过 8 个时，选择框排成 3 列。
- 新增专业组「肉搏」（拳套）：肉搏技能达到 3、4 级与白刃 / 枪械一样各获得一个专业，与其他组共享「最多 3 个」的上限。
- 同步包 `SyncSkillsPayload` 专业数组：`[白刃, 枪械, 额外, 肉搏]`；协议版本 31（v1.0.1 起）。
- 需要「手持白刃武器」的技艺（雷剑等按 `Group.BLADE` 判断）自动接受除拳套外的全部基础冷兵器，专业减值按所持武器自身分类计算；拳套不是白刃武器。
- 念动力悬浮武器：接受白刃组冷兵器；伤害类型、伤势等级、破甲取模板；加入专业减值与重武器减值。

## 攻击结算

- 近战：关键属性（轻型武器取力量 / 敏捷较高者）+ 技能 + 武器伤害 − (目标防御 − 破甲削减) − 减值 + 威猛加值。
  - 重武器：−6 器械减值；浮动后若伤害 > 0 再 +2 附加成功（计入伤害上限）。
  - 【双手】单手持用（副手有物品或失去一条手臂）：自然成功数减半。
  - 【威猛】只对玩家目标（格挡防御存在时）：+ min(格挡 / 2, 主技能 / 2)。
  - 破甲：削减量 = min(X, 盾牌 + 盔甲 + 天生防御)（生物为护甲值）；剩余量击破硬度（DamageRules）。
  - 伤势等级 / 伤害类型通过 `DamageRules.noteMelee` 交给结算（冲击武器可切换为 B）。
- 【眩晕】：最终伤害 > 目标耐力 → 武器伤害点晕眩，强韧豁免，不可叠加；生物改为每点 1 轮的减速 + 虚弱。
- 投掷（匕首 / 飞斧 / 飞锤）：按住右键 ≥ 10 tick 投出（速度 2.0）；判定 = 关键属性（轻投掷 = 敏捷，重投掷 = 力量）+ 运动 + 武器伤害 − 防御 − 距离减值 − 专业减值，上限 武器伤害 + 运动 + 力量；距离上限 = 射程 × max(1, 力量)。落地保留 5 分钟，投掷者可捡回。
- 【剧痛】（鞭子）：最终伤害 > 目标耐力 → 武器伤害点剧痛，强韧豁免，不可叠加；生物改为每点 1 轮的虚弱 + 缓慢。
- 【软兵器】（鞭子，`weapons/soft` 标签）：擒抱检定以力量 + 白刃代替力量 + 肉搏。
- 弩（`item/ZsCrossbowItem`，继承原版弩）：按住右键装填（原版固定 1.25 秒，约一个移动动作），只接受弩矢；判定 = 敏捷 + 运动 + 武器伤害 − (防御 − 破甲) − 距离减值（每超出一个射程 −6），上限 武器伤害 × 2 + 运动；超过 8 倍射程无效；发射时单手持用（另一只手有弩矢以外的物品或失去手臂）成功数减半。弩没有专业；被擒抱时不能使用。
- 握持朝向：手持图标中刀刃 / 镰刃 / 斧刃位于图标左上侧（朝前）。弯刀 / 刀 / 长刀已按此镜像修正。
- 波动拳等使用天生武器的技艺：手持拳套时天生武器 +1。

## 负重（`common/LoadManager`）

- 只计标注了重量的物品（目前为基础冷兵器）：背包、盔甲、副手、饰品栏、鼠标上的物品；原版物品与未标注重量的本模组物品（太极拳饰品、邀请函、魔虚罗法阵）不计；TACZ 枪械以后再定。
- S = 力量（≥ 0）：轻 = 10 + 3S，中度 = 2 × 轻 + 2，重度 = 3 × 轻 + 4（公斤）；体型（巨体 / 怪力）每级 ×(1 + 级数)。

| 档位 | 移动速度 | 疾跑 | 闪避防御 | 主动身体检定 |
|---|---|---|---|---|
| 轻 | — | 可 | — | — |
| 中度 | −25% | 可 | −2 | −3 |
| 重度 | −50% | 不可 | −4 | −6 |
| 超载 | −90% | 不可 | −4 | −6 |

- 每 10 tick 统计；`SyncLoadPayload` 同步；背包界面下方负重条（悬停显示上限与效果）；中度以上显示 HUD 状态标签；档位变化时提示。
- 创造 / 旁观模式不受影响。
