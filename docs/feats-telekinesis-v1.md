# 新专长：不死小强 / 狼孩·人猿泰山 / 念动力天赋（v1）

## 不死小强（UNKILLABLE_ROACH，2 级，6 XP）
- 前提：耐力 ≥ 4。效果：生命上限 +2（`FeatEffects.applyModifiers`，修饰符 `feat_roach_hp`）。

## 狼孩 / 人猿泰山（WOLF_CHILD，3 级）
- 前提：智力 ≤ 2。掩码高 16 位存选择（值 + 1）：bit0 变体（0 狼孩 / 1 泰山）、bit1-2 +1 属性（力 / 敏 / 耐）、bit3 已消除文盲、bit4 已消除怕火；每消除一项 +3 XP。
- 建卡保存后变体与属性锁定，已消除的缺陷不可恢复（`BuildCheck`）。智力不能投入 XP（`err.wolf_int`），`attrBonus` 把智力修正为 1、所选属性 +1（不改上限；能量池容量按原始加点）。
- 免疫自然困难地形（与蛮族共用 `terrainImmune` / 客户端 stuck 清除）。
- 空手攻击：`FeatEffects.wildAttack`（DamageRules 攻击提供者）把非不可避免的 B 部分改为 L。
- 文盲（`WildChild` + `ClientWildChild`）：成书 / 书与笔右键、讲台右键在双端取消；客户端拦截 BookView / BookEdit / Lectern / 告示牌编辑界面；附近告示牌文本替换为 OBFUSCATED 副本（WeakHashMap 记录原文，失去缺陷时还原，服务端重发时重新打乱）。Patchouli 指南书不受影响。
- 怕火：每秒扫描 8 格（上下 4 格）内的火 / 灵魂火 / 点燃的营火与燃烧的实体（含自身），在视野锥（dot > 0.35）且视线可达时获得 3 点恐惧（不可豁免，非叠加键 `fire_fear`）。火把不算。
- 泰山：贴墙 + 前进或跳跃 → 竖直速度 = 基础移速 × 2.1585 × 0.5（基础移速的一半）；潜行停住；否则下滑不超过 0.15/tick；服务端贴墙时清除坠落距离。非疾跑起跳附加 0.2 的朝向水平冲量（与疾跑起跳相同）。
- 狼孩：基础移速 +50%（+5 米，`feat_wolf_speed`）；摔绊检定与对抗摔绊 +9（`FeatEffects.tripBonus`：太极海底针、SkillManager 摔绊 `resistTrip`）。

## 念动力天赋（TELEKINESIS_TALENT，2 级，6 XP）
- 前提：决心 ≥ 3、沉着 ≥ 3。获得念动力池 `telekinesis`（特异本质，颜色 #FF9A3C，字形「念」）。
- 拥有该池即习得天生技艺念动力攻击 / 念动力操控（`ArtSkill.innate()`，`Telekinesis.syncInnate`），不可购买。

### 数值（`common/Telekinesis.java`）
| 项 | 公式 |
|---|---|
| 池 | 决心 + 沉着 |
| 恢复 | 每天 3 × 上限；每小时 = 上限 × 3/24（1000 tick）；若 > 6 则每 10 分钟（167 tick）恢复 1/6；长休回满 |
| 有效力量 | 2 × 传奇决心（传奇 = 属性 − 4） |
| 有效敏捷 | 2 × 传奇沉着 |
| 力量检定值 | 有效力量 + 其传奇值 |
| 有效范围 | max(1, 传奇决心 + 传奇沉着) × 5 米 |

### 基础用法
- 能量加值：运动 / 肉搏 / 白刃检定（`PoolEffects.skillBonus`，近战按武器类别技能、远程按运动）。念动力加值 > 3 时优先使用，否则仅在没有常规加值时使用；不与常规能量加值叠加。
- 念动力场：轮盘开关（动作 24，标志 `F_TK_FIELD`）。被攻击时（`Defense.of / vs` 的 consume 分支）花 1 点，防御 + max(0, 有效敏捷 − 破魔)。破魔由攻击方通过 `Defense.breakMagic(target, X)` 声明（太极「挤」= 6），仅对该目标当刻有效。

### 念动力攻击（TK_ATTACK）
- 1 点 · 有效范围 · 一个目标 · 无需姿势。判定 = 心灵值（决心 + 沉着）+ 施放能量加值，上限 = 心灵值 + 有效力量；非接触防御。
- 物理钝击，远程；有念动力天赋时严重（L），否则 B。特效 `TK_CRUSH`（三轴收缩环 → 内爆 + 碎片），第 8 tick 命中。

### 念动力操控（TK_MANIP）
- 1 点 · 持续 决心 × 3 秒。方块交互距离提升到有效范围；超过 5 米时只能使用方块本身（不能破坏 / 放置 / 对其使用物品）。
- 动作（`TkActionPayload`）：
  - 0（空手右键，未对准方块；或正托着东西时任何右键）：掉落物 → 隔空取物（无重力、跟随准星、速度不超过步行速度、移动时自身移速 −50%、潜行拉近、失去视线或超出范围 + 1.5 米即掉落并重新计算坠落）；生物 → 力量对抗（力量检定值 × 浮动 vs 目标力量 × 浮动），胜则推开，潜行则托起到 2.5 米高悬停；再次右键放下。
  - 1（左键）：就绪的悬浮武器依次（间隔 3 tick）飞向准星目标，飞行 5 tick 后结算，单柄冷却 20 tick。判定 = 力量检定值 + 武器技能，修正 = 武器伤害 − 力量前提不足减值，上限 = 武器伤害 × 1.5 + 判定；B 伤害，类型按武器（剑 / 斧 / 扇挥砍、三叉戟 / 刺剑穿刺、重锤钝击）。
- 悬浮武器：快捷栏中除所选格外的近战武器（剑 / 斧 / 三叉戟 / 重锤或长剑 / 巨剑 / 刺剑 / 扇类别，排除枪械），数量 ≤ 有效敏捷，在背后呈扇形悬浮（`TK_BLADES`，客户端 `ClientTelekinesis` + `ItemRenderer`）。
- 网络：`TkStatePayload`（剩余时长、武器列表、托举对象，变化时与每 2 秒同步给本人与周围玩家）、`TkStrikePayload`（出击轨迹）。协议版本 24。
- 客户端 HUD：准星外 24 段细环显示剩余时长，托着东西时内圈有 4 个旋转小点。
