# 技艺特效第一版

## 范围

仅替换四个样板的表现：灵斩、波动拳、八阵图、豪火球。其余 15 个技能保留原实现（包括它们现有的粒子）。

- 灵斩：挥斩动作、青白月牙刃、命中闪与双环。
- 波动拳：双掌动作、短蓄能、客户端插值弹体、端点冲击。
- 八阵图：施术动作、施法者青碧阵纹、目标五行配色阵纹。
- 豪火球：结印动作、橙色锥形火焰几何体、命中爆点与镜头反馈。

新表现不调用粒子系统。ArtFx / FxEventPayload / ClientArtFx 提供统一入口、紧凑事件包及客户端几何渲染。九种能量池颜色与音效组预留在框架中，不代表其余技能已经迁移。

## 战斗规则不变

目标筛选、能耗、增幅、掷骰、防御修正、伤害、点燃与冷却未修改。高速 8 仍是原防御计算参数，不是弹速。

波动拳的蓄力、飞行与端点爆点仅为延后播放的表现；伤害仍在施放时即时结算，因此可能先出现掉血，再出现视觉命中。没有新增可碰撞弹体或延迟伤害机制。其余样板的动作起手也不阻塞即时判定。

命中特效依据当前攻击计算值大于零触发，不是伤害系统最终扣血回执；免疫等后续规则仍可能使最终伤害为零。

## 资源

- `tools/gen_art_anims.py`：生成四个 KosmX/GeckoLib 动作。
- `tools/gen_art_sfx.py`：numpy + soundfile 程序合成九池 × 四层，共 36 个单声道 OGG，同时更新声音索引与中英文字幕。
- 本次没有从爱给网或其他网站下载音效，也没有引入第三方音频采样。
- 动作依赖项目现有 Player Animator 联动；未安装时沿用原有静默降级。

## 生命周期与边界

服务端 tick 队列只执行表现任务，施法者死亡、移除或换维度后取消；服务器停止时清空。客户端切换世界后清空，暂停时不推进寿命，同时最多保留 256 条表现。渲染使用 lightning 的 QUADS 格式、加法混合与深度测试，在 AFTER_PARTICLES 阶段提交。

## 验证状态

按要求未新增或运行测试套件。已人工核对四个样板差异、资源调用名及所用 Minecraft/NeoForge API 签名；这不能替代编译或游戏内验证。

当前约 2 GB 内存环境在 NeoForge `neoFormDecompile` 阶段被操作系统终止（退出码 137）。完整编译未通过、未生成可用 JAR；多人同步、观感、第一人称与光影兼容性尚未在游戏中确认。
